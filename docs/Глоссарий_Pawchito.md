# PAWCHITO — глоссарий

Единые названия для документов, интерфейса и кода. Новый термин сначала добавляется сюда, потом используется.

## Роли

| Термин | В коде | Значение |
|---|---|---|
| Владелец | `owner` | Хозяин питомца. Регистрируется сам. |
| Клиника | `clinic` | Аккаунт ветклиники. Под ним работают администраторы клиники (регистратура). Аккаунт создаёт администратор системы, один на клинику. |
| Администратор | `admin` | Администратор системы: ведёт клиники и их аккаунты. Медицинские данные не видит. Не путать с администратором клиники. |
| Врач | `vet` | Сотрудник клиники. Своего входа нет, его записи ведёт клиника. |

## Питомец и здоровье

| Термин | В коде | Значение |
|---|---|---|
| Питомец | `pet` | Животное владельца: кличка, вид, порода, дата рождения, пол, фото. |
| Выбранный питомец | — | Питомец, по которому показаны главная, дела, календарь, «Здоровье» и лента. Выбор хранится на клиенте. |
| Здоровье | — | Особенности здоровья, дневник и прививки. В интерфейсе — раздел «История». Раньше — «Памятка». |
| Особенность здоровья | `pet_condition` | Постоянная особенность: аллергия или хроническое заболевание. |
| Наблюдение | `observation` | Одна запись дневника: вес, аппетит, энергия, симптомы, заметка. |
| Дневник | — | Все наблюдения питомца. |
| Прививка | `vaccination` | Сделанная прививка. Источник — владелец (из ветпаспорта) или клиника (при итоге приёма). |
| Лента истории | `pet_timeline` | Хронология питомца: наблюдения, прививки, завершённые приёмы, курсы. |
| Фото питомца | `photo_path` | Одно фото. Загружает только клиника после приёма. Без фото — иллюстрация по виду животного. |
| Архивирование | `archived_at` | Скрытие вместо удаления: объект пропадает из списков, история сохраняется. Для питомцев, врачей и клиник; у клиник в интерфейсе — «Скрыть». |

### Статус ухода (`care_status`)

Одно значение у питомца. Выставляет клиника при каждом итоге приёма. Не путать с типом события.

| Значение | В интерфейсе | Смысл |
|---|---|---|
| `routine` | В норме | Плановый уход, отклонений нет. |
| `attention` | Требует внимания | Нужно наблюдать за состоянием. |
| `treatment` | На лечении | Идёт курс лечения. |
| `recovery` | Восстанавливается | Лечение завершено, период восстановления. |
| `prevention` | На профилактике | Вакцинация, обработки и другие профилактические меры. |

## Запись и приём

| Термин | В коде | Значение |
|---|---|---|
| Запись | `appointment` | Бронь времени у врача. |
| Приём | — | Состоявшийся визит — запись в статусе «Завершена». |
| Причина обращения | `reason` | Значение из справочника и необязательный комментарий. Определяет тип события в календаре. |
| Слот | — | 30 минут рабочего времени врача. |
| Итог приёма | — | То, что клиника вносит при завершении: заключение, рекомендации, рецепты, прививки, статус ухода, данные и фото питомца. |
| Рецепт | `prescription` | Назначение: препарат, дозировка, время приёма, длительность. |
| Курс | — | Все дела, созданные по одному рецепту. |

### Статусы записи (`appointment_status`)

| Значение | В интерфейсе |
|---|---|
| `requested` | Заявка |
| `confirmed` | Подтверждена |
| `completed` | Завершена |
| `cancelled` | Отменена |

## Дела и календарь

| Термин | В коде | Значение |
|---|---|---|
| Дело | `reminder` | Всё, что владелец должен сделать для питомца. Единственная сущность, в интерфейсе — «Дела». |
| Дело курса | `source = prescription` | Создаётся автоматически на каждую дозу рецепта. |
| Своё дело | `source = custom` | Создаёт владелец, можно с повтором. |
| Повтор | `repeat_interval_days` | Интервал в днях до следующего дела серии. |
| Просрочено | — | Не хранится: дело «Запланировано», время которого прошло. |
| Календарь | `calendar_events` | Будущие события выбранного питомца: дела, записи, сроки прививок. В интерфейсе — раздел «Дела». |
| Главная | — | Сводка по выбранному питомцу на сегодня. |

### Статусы дела (`reminder_status`)

| Значение | В интерфейсе |
|---|---|
| `pending` | Запланировано |
| `done` | Выполнено |
| `skipped` | Пропущено |

### Тип события (`event_category`)

Классификация событий календаря. Не путать со статусом ухода.

| Значение | В интерфейсе |
|---|---|
| `treatment` | Лечение |
| `routine` | Уход |
| `prevention` | Профилактика |

## Аккаунт

| Термин | В коде | Значение |
|---|---|---|
| Уведомление | `notification` | Сообщение на сайте о действии другого участника или системы. Только внутри сайта. |
| Код восстановления | `recovery_code` | Одноразовый код владельца для сброса пароля. Выдаётся при регистрации и после каждого использования. |
| Временный пароль | `must_change_password` | Пароль клиники, заданный администратором; меняется при первом входе. |
| Access-токен | — | JWT на 15 минут. Фронт хранит его только в памяти. |
| Refresh-токен | `refresh_token` | Токен на 30 дней в httpOnly-cookie; обменивается на новый access-токен. |

## Устаревшие названия

| Не используем | Используем |
|---|---|
| Памятка | Здоровье (раздел «История») |
| Напоминание, задача, задачи по уходу | Дело, дела |
| Удаление питомца, врача | Архивирование |
| Рутина (категория календаря) | Уход |
| Плановый уход, Внимание, Лечение, Восстановление, Профилактика (как статусы) | В норме, Требует внимания, На лечении, Восстанавливается, На профилактике |
| My pet, Care inbox, Care journey, Pet memory, Medical records (разделы макета) | Главная, Дела, Курс лечения, История, Записи к врачу — [бизнес-правила, §11](Бизнес-правила_Pawchito.md#11-интерфейс) |
